核心客群：亲子家庭
演示链路：游前规划 → 游中陪伴 → 游后留存
版本日期：2026 年 7 月\n\n01 / 项目总览\n从“被动导览”到“持续陪伴”\n网页展示的是一条可被实际体验、可被业务验证的全周期 Agent 链路。\n一句话定义  为每组游客匹配一位可持续记忆的 AI 动物伙伴：游前共创路线，游中感知位置与客流并动态改线，游后将足迹、互动与照片生成可珍藏、可分享的旅行记忆。\n长隆命题要求从“游前感知—游中沉浸—游后留存”的全周期游客视角出发，用 AI 重塑人与乐园空间的连接，并让体验自然穿梭于酒店、乐园、餐饮、零售与娱乐衍生品。奇遇长隆以“统一旅程状态 + 多 Agent 协作 + 空间触发 + AIGC 记忆生成”回应这一要求。\n核心问题\n信息分散：地图、排队、餐饮、演出与任务彼此割裂，游客仍要自己完成复杂决策。\n推荐静态：传统路线无法响应疲劳、拥堵、临时如厕、天气变化等现场变量。\n互动被动：动物讲解往往是固定内容，缺少位置、角色、年龄与连续记忆。\n旅程中断：离园后照片与轨迹散落，情绪价值无法沉淀为传播、复游和消费。\n三阶段价值闭环\n\n命题来源：2026 AI 先锋未来人才大赛“长隆集团”命题页（访问日期：2026-07-19）。网页原型以竞赛场景演示为目的，涉及客流、排队、定位和商业接口的数据均在文末明确区分“仿真验证”与“生产接入”。\n\n02 / 系统逻辑\n一份旅程状态，驱动四类 Agent 能力\n核心不在页面数量，而在数据与记忆能否跨页面连续。\n\n图 1  奇遇长隆统一 Agent 闭环\n统一旅程状态\njourneyProfile｜游客画像：同行成员、年龄、节奏、时间窗、兴趣、饮食及特殊需求。\ncompanion｜伙伴身份：所选动物 Agent、性格语气、关系进度与历史记忆。\nitinerary｜动态行程：站点顺序、预计时间、路网距离、推荐理由与备选点。\nliveContext｜实时环境：当前位置、地理围栏、客流、排队、天气和现场反馈。\nachievements / media｜成果资产：任务、徽章、照片授权、伙伴留言、回忆短片与票根。\n连续性的关键  游前不是一次问卷，游中不是另一张地图，游后也不是孤立相册。每一次选择、抵达、提问和任务完成都会写回同一份 journeyRecord，并成为下一阶段的上下文。\n三条产品原则\n1）先理解再推荐：每一条路线都说明“为什么适合你”；2）主动但可控：Agent 可提出调整，但保留用户确认与撤销；3）把位置变成内容入口：只有抵达真实展区，才唤醒对应的动物故事、任务和知识。\n\n03 / 页面架构\n四个核心路由，完成一次完整旅程\n网页以移动端纵向体验为主，通过明确的阶段路由和共享状态串联。\n\n全局导航与状态流转\n底部导航保留“地图—服务—伙伴—结束”四个稳定入口，既保证主线任务，又允许游客在真实园区中随时偏离路线。核心状态依次为：draft（采集中）→ ready（路线已生成）→ active（游园中）→ adjusted（发生过改线）→ completed（已结束）→ archived（已生成记忆资产）。\n页面共通反馈\n进度可见：游前显示 1/7 等对话轮次，游中显示 0/3 站与伙伴任务进度。\n原因可见：路线站点与改线结果均展示距离、等待、适配原因或被替换原因。\n状态可逆：允许重选伙伴、回到实时地图、重新生成路线/票根，减少一步走错的焦虑。\n异常有兜底：无定位、知识不确定、紧急服务或未授权照片时，页面提供替代入口而非中断体验。\n\n04 / 游前逻辑\nAI 逐问逐答，把模糊需求变成真实路线\n团团不是先给答案，而是通过短对话逐步建立可计算的旅程约束。\n\n图 2  游前：通过自然对话理解同行结构与偏好\n对话采集顺序\n选择动物伙伴：团团（温柔亲子科普）、凯凯（行动型探险）、悠米（松弛休闲）。\n确认同行结构：亲子家庭、情侣、朋友结伴或独自出游，并记录成人/儿童人数。\n选择游览节奏：效率优先、适度探索或悠享慢游。\n设置时间窗：预计入园与离园时间，形成路线硬约束。\n按优先级选择动物：本次演示为熊猫园、考拉馆、长颈鹿园。\n确认园内用餐需求：为后续插入用餐节点与错峰建议提供依据。\n补充自由文本：如“孩子下午容易累，希望少走回头路”。\n确认摘要并生成路线：Agent 汇总条件，用户可返回修改后再计算。\n路线生成逻辑\n概念评分  站点评分 = 偏好匹配 + 动物活跃时段 + 时间窗适配 + 科普/互动价值 − 步行成本 − 排队风险 − 疲劳惩罚。随后在园区路网中计算满足硬约束的低回头路线，并保留弹性点与备选点。\n输出不只是一张地图，还包括：总里程与预计时长、时间轴、每段步行距离、每一站的推荐理由、用餐/休息节点以及遇到高峰或闭园时的替代项。当前原型用模拟站点、路网与排队数据验证交互闭环；生产版需接入真实 GIS、营业时间、动物活跃时段、演出和餐饮接口。\n\n05 / 游中逻辑\n抵达的那一刻，知识主动发生\n全局行程 Agent 负责调度；空间动物 Agent 只在正确的地点、正确的时机被唤醒。\n\n图 3  游中：实时路线、50m 电子围栏与区域互动\n演示链路与状态变化\n选择“按计划探险”后加载游前路线，进入 LIVE GIS 实时地图。\n点击“模拟前往长颈鹿园”，位置沿路线变化；进入 50m 围栏后出现“演示抵达”。\n确认抵达后，系统解锁“开始这一站”，并写入实际足迹与到达时间。\n进入长颈鹿园现场奇遇站，完成“高处取食挑战”，选择“舌头”获得任务反馈与徽章进度。\n向“高空瞭望员”提问“长颈鹿的舌头为什么这么长？”，由受约束的知识问答返回答案。\n返回实时地图，选择“前面排队很长，帮我调整路线”，全局 Agent 重排后续顺序并解释变化。\n两类触发机制\n空间触发：电子围栏（原型为 50m）负责判断“游客是否真正抵达”，二维码/NFC 可作为定位不稳定时的备用入口。事件触发：客流升高、天气变化、游客疲劳、临时如厕或项目关闭等事件写入 liveContext，触发路线重新评估。\nAgent 回答边界\n动物知识来自经过审核的知识库，回答必须可追溯，并明确区分事实、推测与趣味表达。\n根据儿童/成人切换表达深度；不提供危险接近、投喂或干扰动物的建议。\n对医疗、安全、走失等紧急情境直接提供人工服务入口，不由生成式模型独立处置。\n改线建议必须说明原因与影响，用户可保持原计划或撤销调整。\n\n06 / 游后逻辑\n把零散瞬间，编织成完整旅行故事\n离园不是服务终点，而是记忆沉淀、社交传播和复游运营的起点。\n\n图 4  游后：足迹、成就、回忆短片与票根入口\n内容聚合逻辑\n计划与实际：对照原始路线和真实足迹，保留发生过的改线与临时发现。\n成就与证据：把展区抵达、观察任务、问答和徽章组成可回看的“认真观察过的证明”。\n伙伴叙事：动物 Agent 根据当天互动生成短留言，使回忆保持角色一致性。\n授权媒体：仅使用游客主动选择的照片/视频；没有照片时仍可用地图、徽章和插画完成基础版。\nAIGC 回忆短片\n记忆引擎按照“出发—抵达—互动—变化—完成”的叙事节奏，把路线足迹、徽章、伙伴留言、票根和授权照片组织为 15—30 秒的 H5 回忆短片。用户可预览、逐幕查看、替换素材或关闭，不把“自动生成”变成不可控的黑箱。\n奇遇票根\n票根编辑页提供三种风格，包括动物伙伴票。用户可设置封面照片、缩放裁切、标题、旅程留言与分享文案，并导出长图或 9:16 视频封面。票根将真实行程数据压缩为一个可保存、可分享、可制作实体纪念品的情绪载体。\n\n07 / 内容系统\n同一套园区知识，不同的角色与陪伴策略\n多 Agent 的差异不只是头像，而是语气、路线策略、任务类型和情绪反馈的系统性差异。\n\n内容分层\n基础服务层：路线、距离、等待、营业时间、厕所、母婴室、餐饮和演出提醒。\n沉浸互动层：角色问候、在地科普、观察任务、即时问答、徽章与好感度。\n情绪记忆层：伙伴寄语、回忆短片、票根、动物图鉴与下一次相见的伏笔。\n商业承接层：与已发生的需求和情绪相关的餐饮、零售、酒店与纪念品建议。\n内容治理\n知识内容采用“官方资料/专家审核知识库 + 检索增强生成 + 规则约束”的组合；角色可以有温度，但事实不能被人设改写。系统记录知识来源、版本与敏感规则，对不确定问题明确说明并提供人工咨询入口。未成年人、定位、照片和生物安全相关内容采用更严格的默认权限与提示。\n文案原则  伙伴要像一个真正同行的人：主动但不打扰、温柔但不幼稚、解释但不说教、推荐但不硬卖。\n\n08 / 多业态闭环\n让情绪价值自然转化为服务与消费\n商业转化不是额外弹窗，而是把正确的服务放到正确的时间、地点和情境中。\n\n商业闭环的三次转化\n第一次是服务转化：用错峰、排号、导航解决即时问题；第二次是情绪转化：把刚完成的互动变成主题商品或定制纪念；第三次是关系转化：用动物伙伴记忆、未完成图鉴和季节新路线推动会员与复游。每一次转化均由用户需求或旅程事件触发，并提供清晰的跳过、撤回与退订。\n核心判断  如果推荐不能同时提升用户体验，就不应被视为合格的商业触点。\n\n09 / 数据与技术\n原型验证闭环，生产环境连接真实业务\n当前网页证明交互与系统逻辑可行；规模化落地依赖数据接口、内容治理和隐私机制。\n能力分层\n体验层：移动端 H5，包括对话式采集、地图路线、展区奇遇站、游后回顾与票根编辑。\nAgent 编排层：统一管理伙伴人设、旅程记忆、工具调用、事件触发、权限和人工兜底。\n智能能力层：多约束路线规划、地理围栏、动物知识 RAG、内容审核、AIGC 图像/视频/文案。\n数据服务层：GIS 路网、项目与展区、客流排队、天气演出、餐饮零售、酒店票务和会员。\n治理层：定位与媒体授权、未成年人保护、数据最小化、日志审计、知识版本和模型安全。\n原型数据与生产数据边界\n\n\n10 / 验证指标与路线图\n用体验、运营与商业三组指标证明价值\n原型的目标不是证明所有接口已经存在，而是证明一个值得接入真实数据的业务闭环。\n建议指标\n\n分阶段路线图\nMVP 验证：完善三段网页闭环，以仿真数据完成 5—8 组亲子家庭可用性测试。\n小范围试点：选择一个园区与 2—3 个明星动物展区，接入地图、营业时间和有限实时数据。\n业务联动：接入餐饮排号、零售库存、票根纪念品和酒店/班车信息，验证二次消费指标。\n规模化运营：建立内容审核后台、跨园区数字身份、会员权益和长期动物伙伴记忆。\n主要风险与应对\n定位漂移通过“围栏 + 信标/扫码确认”降低误触发；路线建议通过原因说明和用户确认降低自动化焦虑；动物知识以官方/专家审核与来源追溯控制事实风险；未成年人、照片与位置数据采用最小必要采集、分级授权、可删除与限期存储；涉及支付、医疗、安全和紧急事件时由业务系统或人工服务兜底。\n\n11 / 演示说明\n三分钟讲清“感知—沉浸—留存”\n评审看到的不只是三张页面，而是一份连续增长、持续记忆的 journeyRecord。\n推荐演示脚本\n游前（60 秒）：选择团团与亲子家庭，设为悠享慢游、10:00—18:00，选择熊猫/考拉/长颈鹿，勾选园内用餐并补充“孩子下午容易累，希望少走回头路”，生成路线。\n游中（80 秒）：选择按计划探险，展示实时地图与 50m 围栏；模拟抵达长颈鹿园，完成高处取食挑战并提问；返回地图，报告排队很长，展示改线结果。\n游后（40 秒）：展示计划与实际、成就徽章和照片位；播放回忆短片，进入票根编辑页，切换“动物伙伴票”，展示分享文案与导出入口。\n演示时应强调的四句话\n我们不是在地图旁边增加一个 AI 对话框，而是让同一个 Agent 贯穿整个旅程。\n位置不是一个坐标，而是动物知识、任务与角色故事的入口。\n每一次改线都可解释、可选择；每一次内容生成都建立在用户授权之上。\n商业推荐由真实需求和情绪节点触发，既提升体验，也为多业态创造自然增量。\n结语  奇遇长隆把“规划工具”升级为“关系型服务”：它记得游客是谁、此刻在哪里、今天发生了什么，也知道下一次为什么值得再来。\n原型与素材索引\n网页演示地址：qiyucl.site/pretrip、qiyucl.site/inpark、qiyucl.site/posttrip。配套宣传片、页面录屏、角色图与票根素材已用于本说明书插图。比赛命题依据：https://activity.feishu.cn/future-talent?detail=chimelonggroup。\n---TABLES---\n阶段
